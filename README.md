# English Habit

## 项目简介

English Habit 是一个 AI 陪伴英语学习产品。

目标用户：

准备四六级但难以坚持学习英语的大学生。

核心理念：

帮助用户真正学会英语。

AI陪伴、成长感和激励机制只是帮助用户坚持学习的手段，而不是最终目的。

---

## 当前阶段

MVP验证阶段

当前验证目标：

用户是否更愿意使用：

AI陪伴 + 英语学习

而不是传统背单词软件。

---

## 产品定位

这不是：

* 单纯背单词软件
* AI聊天软件
* 英语课程平台

而是：

一个帮助用户长期坚持学习英语的 AI 学习伙伴。

---

## 当前技术栈

* HTML
* CSS
* JavaScript

纯前端项目。

暂不使用：

* 数据库
* 登录系统
* 支付系统
* 后端服务
* 云同步

---

## 当前开发重点

验证：

AI搭子 + 英语学习

是否能够提升用户坚持学习的意愿。
