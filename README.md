# English Habit

## 项目简介

English Habit 是一个帮助大学生坚持学英语的每日习惯工具。

目标用户：准备四六级但难以坚持学习英语的大学生。

核心理念：**先把英语学习做到极致，再让 AI 锦上添花。**

---

## 当前阶段

**Phase A — 纯学习引擎**

- 520 个 CET-4 高频词汇，每个词配有音标、例句和中文翻译
- SM-2 间隔重复算法：不认识的在 1/3/7/14/30 天后自动重现
- Web Speech API 发音：点击即可听到标准美式发音
- 每日学习：10 个新词 + 待复习词，每天 10 分钟完成
- 学习日历：90 天热力图，直观看到坚持轨迹
- 词汇分布：已掌握 / 复习中 / 学习中 / 未学习，清晰分类

---

## 产品定位

这不是：

- 单纯背单词软件
- AI 聊天软件
- 英语课程平台

而是：

一个帮助用户**真正坚持每天学英语**的工具。

AI 陪伴功能将在学习引擎打磨完善后加入（Phase C）。

---

## 当前技术栈

- HTML + CSS + JavaScript
- localStorage 持久化（key: `english_habit_v5`）
- Web Speech API（发音）
- 纯前端，无后端，无登录
